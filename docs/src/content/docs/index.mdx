---
title: EventLoom
description: An opinionated event sourcing framework for .NET and EF Core.
---

EventLoom is an event sourcing framework for .NET 10 applications using EF Core.

It uses a dedicated event-store context and supports PostgreSQL and SQLite. The project is designed around reliable appends, optional multi-tenancy, snapshots, asynchronous projections, and distributed PostgreSQL deployments.

## Status

EventLoom is in early development. The initial repository foundation is complete; the domain kernel is next.
